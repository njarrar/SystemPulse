# Pulse for Windows 11

`Pulse-win-x64.zip` (most PCs) and `Pulse-win-arm64.zip` (Arm PCs such as Surface Pro X or Snapdragon laptops). GitHub Actions builds them from `native/win11` on every change and places them here.

Unzip anywhere and run `Pulse.exe`. Pulse lives in the notification area next to the clock. Built for Windows 11 22H2 or later.
