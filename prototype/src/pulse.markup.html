RTL design guidelines for Arabic إرشادات التصميم من اليمين إلى اليسار
How Pulse handles Arabic across all six platforms. Switch the flyout to ع above to see each rule in context.
01Mirror the whole layout
Set dir="rtl" on the shell. The flyout anchors to the left, and the menu bar, taskbar and header order reverse. Write every offset with logical properties (inset-inline-end, padding-inline, margin-inline-start), never left/right.

02Time always flows left to right
Charts and sparklines are never mirrored. Wrap them in dir="ltr" so the past sits on the left and “now” on the right, in both languages. Only the axis labels are translated.
DO

03Flip direction icons only
Mirror icons that point along the reading direction: chevrons, Back, external link (transform: scaleX(-1)). Leave non-directional icons alone: thermometer, battery, Wi-Fi, check marks, the logo and the CPU waveform.
DO

04Isolate numbers with units
Keep Western digits (0–9) with tabular-nums. The locale engine wraps every value it inserts in Unicode isolates (U+2068 … U+2069); values that stand alone sit in a dir="ltr" span. Without this, the bidi algorithm reorders them.

05Latin names inside Arabic sentences
App and brand names stay in Latin (Xcode, Norton AntiVirus, Pulse). A sentence that starts with one must use dir="rtl", not dir="auto", or it runs left to right. Fields that hold only a name use dir="auto" so the start of the name is never clipped.

06Arabic type and line height
Use IBM Plex Sans Arabic (macOS, Windows 11), Noto Sans Arabic (ChromeOS, Linux) and Tahoma (XP, 98 SE). Pin line-height: 1.3 on the flyout: Arabic fonts add about 80px of height across it otherwise. No letter-spacing, no uppercase, 11px minimum.

07Use real Arabic plurals
Arabic has six count forms, picked by CLDR rules on the last two digits: 3–10 and 103–110 share one form, 11–99 another, and 100–102 use the plain form. The rules and forms live in locales/ar.json, so code never builds “number + noun”.

08Bars, gradients and sliders start at the start side
Progress bars fill from the inline start (right). Directional gradients flip to 270deg. Sliding pills (segmented control, EN | ع, switches) move with inset-inline-start.

09Keep technical identifiers in Latin
Translate UI copy, but keep units and identifiers as written: PID, GB, MB/s, ZRAM, Wi-Fi 6E, wlp1s0, APFS, °C/°F. Arrows in Arabic copy point left: «انقر لعرض آخر 10 دقائق ←».

10Test the longest strings
Arabic labels often run longer than English. Check them at full size: «خدمة مكافحة البرمجيات الضارة» · «أكثر التطبيقات استهلاكاً». Fixed-width labels use nowrap + ellipsis, which appears on the left in RTL.
